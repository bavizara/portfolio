## Run it

No build step is needed. Either:

- Double-click `index.html` to open it in a browser, or
- Serve the folder with any static server, for example `python -m http.server 8000` and then open http://localhost:8000

Google Fonts (Cormorant Garamond and JetBrains Mono) load from the internet. Without a connection the page falls back to Times New Roman and Consolas.

## Customising

- **Colors:** edit the CSS variables at the top of `css/styles.css` (`--gold`, `--royal-2`, `--obsidian`, and so on).
- **Content:** edit the sections in `index.html`.
- **Typing roles:** edit the `roles` array in `js/script.js`.
- **Marquee items:** edit the `items` array in `js/script.js`.
- **Animations:** the page respects the operating system's reduced-motion setting, so animations are turned off for users who prefer less motion.
